How costs are calculated

Direct usage is cost created specifically by this team’s work: model and token consumption, agent executions, tool and API calls, dedicated infrastructure, and team-specific data retrieval.

Shared allocation is this team’s transparent share of platform services used by all teams, including governance controls, shared agents, the model gateway, monitoring, audit, security, and shared storage.

The shared platform pool is allocated by each team’s percentage of governed executions. More executions means a larger share of shared platform cost.
